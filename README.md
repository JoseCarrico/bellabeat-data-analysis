# 📊 Bellabeat Case Study: Análise de Bem-Estar e Saúde

## 📝 Sobre o Projeto
Este projeto analisa dados de dispositivos inteligentes da **Bellabeat** para identificar tendências de utilização e hábitos de saúde das mulheres. O objetivo é fornecer recomendações estratégicas para o departamento de marketing da empresa.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** R
* **Bibliotecas:** Tidyverse (dplyr, ggplot2, tidyr, lubridate), Janitor.
* **Ferramenta de Análise:** Kaggle Notebooks / RStudio.

## 🔍 Principais Insights (Business Intelligence)
* **Atividade Física:** Os participantes caminham em média 7.638 passos/dia, abaixo dos 10.000 recomendados pela OMS.
* **Identificação de Risco:** Detetou-se uma forte correlação negativa entre passos totais e tempo sedentário (r = -0.33), indicando áreas de intervenção para melhorar a saúde dos utilizadores.
* **Eficiência do Sono:** A maioria dos utilizadores tem uma eficiência de sono acima de 90%, mas o tempo na cama é significativamente superior ao tempo de sono real.

## 🚀 Recomendações Estratégicas
1. **Gamificação de Passos:** Implementar notificações push para atingir a meta de 10k passos.
2. **Higiene do Sono:** Criar alertas baseados nos dados de "Time in Bed" para otimizar o descanso.
